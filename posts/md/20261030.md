# Hiding Chrome Bookmarks

In Chrome (and Chrome-like browsers), the built-in settings currently do not
support hiding bookmark subsets from the address bar. I recently found a simple
and efficient way to do so with a single character: the humble underscore.

For each uniform resource locator (URL) \(S\texttt{://}O\) of each bookmark to
be hidden:

- Prepend \(O\) with \(\texttt{\_}\).
- In \(O\):
  - Append each \(\texttt{.}\), \(\texttt{/}\), \(\texttt{?}\), \(\texttt{=}\),
  \(\texttt{+}\), \(\texttt{\&}\), and \(\texttt{\#}\) with \(\texttt{\_}\).
  - Prepend[^1] each \(\texttt{:}\) with \(\texttt{\_}\).

For example,
\(
	\texttt{https://}
	A
	\texttt{.}B
	\texttt{:}C
	\texttt{/}D
	\texttt{?}E
	\texttt{=}F
	\texttt{+}G
	\texttt{\&}H
	\texttt{=}I
	\texttt{\#}J
\)
becomes:

\[
	\texttt{https://}
	\texttt{\_}A
	\texttt{.\_}B
	\texttt{\_:}C
	\texttt{/\_}D
	\texttt{?\_}E
	\texttt{=\_}F
	\texttt{+\_}G
	\texttt{\&\_}H
	\texttt{=\_}I
	\texttt{\#\_}J
\]

Then, in the address bar, type:

- \(\texttt{\_}X\) to search for \(X\), where \(X\in\{A,B,D,E,F,G,H,I,J\}\).
- \(\texttt{\_:}C\) to search for \(C\).

The method works because bookmarks use prefix matching, and the encoding
effectively creates a "hidden realm" for bookmarks!

[^1]: Unfortunately, *appending* seems buggy with the current user interface for
      bookmark management.
